# Backup index

Последна актуализация: 2026-09-25.

Локалните WAV файлове са изключени от Git. След завършването на
`pilot_01` е предвиден локален архив:

- `backups/SmartVoiceHome_pilot_01_2026-09-25.zip`
- съдържа `data/stt_validation/pilot_01/` с WAV файловете и всички
  append-only `manifest.jsonl` файлове, включително отхвърления MX04 опит;
- SHA256 трябва да се провери с `Get-FileHash` след създаването му.

При тази сесия архивът не беше създаден: Windows отказа запис в
`backups/`, а заявката за разрешение за тази операция беше отхвърлена.
Това трябва да се довърши отделно с разрешен локален backup. Архивът ще е
извън Git според `.gitignore`. При преместване на проекта трябва
да се копират едновременно архивът и version-controlled каталогът
`docs/STT_VALIDATION_PILOT_01.md`.
